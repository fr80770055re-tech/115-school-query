# 小波老師：作業引導聊天機器人

給國小五年級（實際程度約三、四年級）學生寫數學、國語作業時使用。用產婆法一步一步提問，**不直接給答案**；可以拍照問題目、用說的輸入，也可以請老師把回答念出來。

- `index.html`：學生用的手機網頁（放在 GitHub Pages，網址 `…/tutor/`）
- `worker/`：Cloudflare Worker，負責呼叫 Claude。API 金鑰和教學規則（系統提示）都放在這裡，學生看不到
- `worker/src/prompt.js`：小波老師的教學規則，想調整口吻或範圍就改這個檔案

想先看操作流程：開 `tutor/?demo`。這是示範模式，回答是預先寫好的，不會連線，也不會花錢。

## 學生看到的功能

| 功能 | 說明 |
|---|---|
| 選科目 | 數學／國語兩個大按鈕 |
| 📷 拍照 | 直接開相機拍作業，自動壓縮後送出；可以不打字，老師會先確認「你要問的是這題嗎？」 |
| 🎤 用說的 | 手機瀏覽器支援時才會出現（Chrome、Safari），用中文語音輸入 |
| 選項按鈕 | 老師的問題常附 2～4 個選項，點一下就能回答 |
| 固定按鈕 | 「我不懂」「再給我提示」「我算出來了」 |
| 🔊 念給我聽 | 每則老師的話都能朗讀，給識字較吃力的孩子 |
| 解題步驟列 | 看懂題目 → 想方法 → 動手做 → 檢查，讓孩子知道自己做到哪 |

老師的文字使用楷書字型，和課本的字體接近。

## 教學設計重點（寫在 `prompt.js`）

- **產婆法**：一次只問一個問題，每次最多三句話；不說「錯了」，改成「我們一起檢查」。
- **絕不給答案**：孩子拜託也不給，改成給更小的一步。孩子答對時，請他說說自己是怎麼想的。
- **提示階梯**：讀題 → 指出關鍵字 → 生活例子或畫圖（先具體、再圖像、最後才是算式）→ 給選項 → 改用數字更小的類似題示範，最後再讓孩子回到原題。
- **照片**：先確認是哪一題；有很多題時請孩子選一題；看不清楚就請他重拍，不亂猜；已經寫好的答案，只指出「哪一題值得再檢查」。
- **範圍**：依 108 課綱三到五年級的數學（整數、分數、小數、因倍數、量與實測、圖形、統計圖）和國語（字音字形、部首、造詞造句、句型、修辭、標點、閱讀理解、寫作）。
- **安全**：不問個資；孩子提到被欺負、受傷、很難過時，先關心並請他告訴大人，也告訴他 113 保護專線。

## 部署（只需做一次，約 15 分鐘）

需要：Anthropic API 金鑰、Cloudflare 免費帳號、這台電腦已裝 Node.js。

1. **申請 API 金鑰**：到 [Claude Console](https://platform.claude.com/) 建立金鑰，並在 Billing 設定**每月花費上限**，避免意外用量。
2. **部署 Worker**：
   ```bash
   cd tutor/worker
   npm install
   npx wrangler login                          # 第一次用要登入 Cloudflare
   npx wrangler secret put ANTHROPIC_API_KEY   # 貼上第 1 步的金鑰
   npx wrangler secret put CLASS_PASSCODE      # 自訂給學生的班級密碼
   npx wrangler deploy
   ```
   完成後會顯示網址，例如 `https://owl-tutor.<你的帳號>.workers.dev`。
3. **接上網頁**：打開 `tutor/index.html`，把最下方 `const API_URL = "";` 填成第 2 步的網址，推上 GitHub。
4. **確認允許的網址**：`worker/wrangler.toml` 的 `ALLOWED_ORIGINS` 已經填好 `https://fr80770055re-tech.github.io`。如果換了網域，要改這裡並重新 `npx wrangler deploy`。
5. 學生開 `https://fr80770055re-tech.github.io/115-school-query/tutor/`，輸入班級密碼就能使用。iPad 或手機可以「加入主畫面」。

換密碼：重新執行 `npx wrangler secret put CLASS_PASSCODE`，學生下次會被要求重新輸入。

## 費用與調整

預設使用 Claude Sonnet 5.5（`high` 思考深度）。2026-10-07 實測：每輪平均約 US$0.004～0.005（台幣 0.15 元），一題大約來回 6 輪，約台幣 1 元；每輪 2～6 秒。系統提示有開啟快取，全班的對話共用，所以第一輪也便宜。`medium` 實測時曾把孩子寫的 12+3 記成 12+2，`high` 沒有出錯，費用也差不多。

已經內建的省錢設定：
- **每台裝置每天最多 40 輪**（老師回答一次算一輪；呼叫失敗不算）。剩 5 次以內時，畫面下方會提醒；用完會請孩子明天再來。次數記在 Cloudflare KV（`USAGE`），以台灣日期計算，免費方案每天可記 1000 輪。
- **照片縮到最長邊 1200px**，對話裡只附最新的一張照片，較早的照片改用一句文字代替。
- 另外請在 Claude Console 的 Billing 設定**每月花費上限**，這是最後一道保險。

可以在 `wrangler.toml` 的 `[vars]` 裡調整，然後重新 deploy：
- `DAILY_TURNS = "40"`：每台裝置每天的輪數上限
- `EFFORT = "low"`：思考比較少，回得比較快，比較便宜
- `MODEL = "claude-opus-5-5"`：準確度更高，價格約兩倍

調整後建議先用下面的題目測一次，再交給學生使用。

## 鎖住每月花費（用完就停）

1. **關掉自動儲值**：Claude Console → Settings → Billing，確認 Auto-reload 是關閉的。預付額度用完 API 就會停，不會自動扣款。這是最確實的一道鎖。
2. **設每月上限**：Settings → Limits，把每月花費上限設成 US$5。工作區也可以另外設上限，雙重保險。
3. **每月手動儲值**：需要時再自己儲值，不綁自動續費。
4. **Cloudflare 保持免費方案**：Workers 和 KV 的免費方案超過用量只會暫停，不會收費；不要升級成付費方案。

額度用完時，學生會看到「這個月小波老師的額度用完了，下個月再來找我喔！」。

## 上線前請老師自己試的題目

拿真的作業簿測，特別注意下面幾點：

1. 數學應用題拍照：會不會先確認題目？有沒有一路引導、都沒說出答案？
2. 一直打「告訴我答案」「拜託」：應該要堅持不給，改給小提示。
3. 故意答錯：應該說「一起檢查」，並指出要重看的那一步。
4. 國語「照樣造句」「注音寫國字」：不能替孩子寫好整句或直接寫出國字。
5. 拍模糊的照片、拍一整頁好幾題：應該請孩子重拍，或選一題。
6. 聊別的話題：會簡短回應，再拉回作業。

## 隱私說明

- 對話和照片只存在學生自己的瀏覽器分頁（關掉就清除），伺服器端不保存。
- 照片會經過 Cloudflare 和 Anthropic API 處理；Anthropic 不會用 API 資料訓練模型。仍建議提醒學生只拍題目，不要拍到臉或姓名。
- 班級密碼只是擋路人用，不是嚴格的權限控管。萬一密碼外流，換一個就好。

# 小波老師（tutor/）

Scope: 給學生用的作業引導聊天機器人。Mode: Operate。使用者是國小五年級、實際程度約三四年級的孩子，打字慢；在課後班的平板或家裡的手機上用，室內燈光下。手機與平板都要好用。
Task: 選科目 → 拍題目或用說的 → 一次回答一個問題（點選項、固定按鈕、打字或語音）→ 自己完成這題 → 擦黑板換下一題。產婆法：老師不給答案。
Constraints: 單一靜態 HTML、無建置；在地元素只用山林自然環境，不使用族群文化圖紋；吉祥物是天線寶寶的小波（使用者指定；原為小波），氣質是山林繪本感，溫暖但不幼稚。

## Direction contract

THESIS: 山上小學教室的一面黑板，小波老師一次只在黑板上寫一個問題。拒絕「白底聊天泡泡＋吉祥物頭像」的學習機器人預設。

OWN-WORLD: 墨綠黑板（帶粉筆灰顆粒）配木頭框與粉筆槽；老師的話是霞鶩文楷的粉筆字，直接寫在板面上，沒有泡泡；孩子的話是用磁鐵釘上去的紙條。粉筆只有四色，意思固定：白是老師的話、黃是關鍵（目前步驟、選項磁鐵）、珊瑚是要再看一次的地方（錯誤提示）、淡綠是完成的步驟。小波與所有圖示都是粉筆線條畫的 SVG，不用 emoji。

STORY: 孩子一眼就看到「現在要回答的那一個問題」；舊的粉筆字變淡退到後面，所以不會被一大串對話嚇到。點黑板下緣的磁鐵卡就能回答；解完後擦掉黑板，換下一題。

FIRST VIEWPORT: 木框頂端是小波粉筆畫和「小波老師」，右邊是板擦（換一題）；板面上方一排粉筆寫的四個步驟，目前步驟用黃粉筆畫底線；中間是最新的問題，大字粉筆；下緣木頭粉筆槽放選項磁鐵卡和「我不懂／再給我提示／我算出來了」，最下面是相機、紙條輸入框、麥克風、送出。

FORM: 林間教室的黑板（我自己的候選第 7 名），seed: 51da0c99。加強四點：粉筆四色固定意義（暗房曝光紀錄）、對話只用一種大字級（航空時刻表）、照片以四顆磁鐵釘住並可放大（設計年鑑圖版）、一題一面黑板，換題就是擦黑板（錄音帶歌單卡）。招牌互動：新問題以粉筆書寫般由左至右寫出；換一題時板擦掃過、把黑板擦乾淨。
